# A05 Final Evidence Synthesis

This build consolidates the final matched-control evidence for manuscript,
Supporting Information, figures, and reviewer response.

It does not rerun matching, models, candidate generation, property scoring,
B5 selection, or statistical inference.

Authoritative interpretation:

- 178 attribution-selected primary regions across 90 parents formed the
  matching universe.
- 92 regions (51.69%) were strictly matched across all five matching seeds.
- These matched regions covered 65 parents (72.22% of the matching universe).
- Primary paired outcome inference uses all 65 matched parents.
- Target-window B=5 effect: +10.15 percentage points.
- Strict-success B=5 effect: +6.09 percentage points.
- Observed-only distance and final-edit-score endpoints are reported only
  as 58-parent complete-observation sensitivity analyses.
- Parent is the inferential unit.
- No causal or wet-lab claim is supported.
